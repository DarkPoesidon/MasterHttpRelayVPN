تمام کدهای هسته (پراکسی، مدیریت سرتیفیکیت و...) داخل همین پوشه قرار دارن و هیچ وابستگی خارجی ندارن.

برای اینکه خودت فایل .exe رو بیلد بگیری، این ۳ مرحله ساده رو انجام بده:

۱. فایل Zip رو اکسترکت کن و ترمینال (CMD یا PowerShell) رو داخل همین پوشه Windows باز کن.
۲. پیش‌نیازها رو نصب کن:
pip install -r requirements.txt pyinstaller
۳. اسکریپت بیلد رو اجرا کن:
python build.py

✅ تمام! اسکریپت به صورت خودکار فایل اجرایی VPN.exe رو به همراه آیکون و متادیتا داخل پوشه dist (که همونجا ساخته میشه) قرار میده. حالا می‌تونی برنامه رو باز کنی و با وارد کردن آیدی گوگل اسکریپت خودت، به راحتی ازش استفاده کنی.
